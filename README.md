## Features

- ✅ **Immersive Hero** — Canvas particle network, floating UI cards, animated stats
- ✅ **AI Chat Demo** — Live streaming UX demonstration
- ✅ **Product Marketplace** — Filterable cards with preview mockups
- ✅ **Seller Economy** — Revenue calculator (interactive), top sellers leaderboard
- ✅ **AI Tools Suite** — Generator, Reviewer, Figma→React Converter, AI Search
- ✅ **Enterprise Tier** — Contact form, pricing, SSO/SAML details
- ✅ **Auth System** — Google/GitHub/Figma OAuth + email registration
- ✅ **Glassmorphism Design** — Dark-first, premium aesthetics
- ✅ **Scroll Animations** — Intersection Observer reveals, staggered children
- ✅ **Responsive** — Mobile, tablet, desktop
- ✅ **Performance** — Static HTML, no dependencies, instant load
